└─ Scored for relevance before inclusion

SKILL MEMORY (Learned Procedures)
├─ Name of procedure

└─ Recalled when similar situation occurs

PERSONALITY STATE (Evolving Identity)
├─ Current mood (confident/anxious/neutral)

└─ Character traits (cautious, curious, paranoid...)

DIARY (Auto-Generated)
├─ Entry every 5 minutes
├─ Summarizes recent events + emotional state
├─ Reads like a narrative


💡 KEY CONCEPTS
════════════════════════════════════════════════════════════════════════════

🔄 ANTI-LOOP MECHANISM
   Action fails → recordFailedAttempt() [count = 1]
   Action fails again → recordFailedAttempt() [count = 2]
   shouldAbortAction() → TRUE ✓ CHANGE STRATEGY

😊 PERSONALITY EVOLUTION
   Death → fear_level +0.1, mood = "anxious"
   Success → fear_level -0.05, mood = "confident"
   Repeated trauma → specific fears increase

📊 MEMORY RETRIEVAL
   Situation: "I see skeleton"
   Score all memories:
   - Relevance: Does it match "skeleton"?
   - Importance: How important is it?
   - Recency: How recent?
   Result: Only top memories included

📝 DIARY GENERATION
   Input: Last 10 events + mood + trauma + goals
   Output: "Today I found diamonds but died to creeper..."
   Frequency: Every 5 minutes
